# Native BIND peer deletion trial — 2026-09-26

This is a bounded P0.4/P0.5, constitutional invariants 1/3/6 observation. It used only fresh disposable Debian 13 and Arch QEMU guests. No installed CelikPanel server was changed.

The current checkout ran `bind__intent__after-write__paired-primary__peer-reachable` in a fresh BIND-primary/panel-free BIND-secondary pair. The controller returned `passed` (result SHA-256 `6d7fd8988a7780f659e2c2beb8e10ed3257966a0ff6620dfcd9b0e1a91d3241f`). Before deletion, the secondary's native `rndc zonestatus s1-kill.test` reported a loaded secondary at SOA serial 2026083101. Its catalog was a loaded secondary at serial 1.

The fixture-only [native owner edit](native_bind_catalog_remove.py) checked the exact guest marker and expected catalog layout, disabled/stopped the primary's Panel and Agent, copied the managed BIND zone declarations into an independent native include, removed the sole `s1-kill.test` PTR member from a separate catalog file, advanced the catalog SOA serial to 2, validated BIND config and reloaded native `named.service`. It did not edit the immutable CelikPanel generation or run a CelikPanel delete request. The secondary transferred catalog serial 2 (nodes 2), and `rndc zonestatus s1-kill.test` returned `no matching zone` rather than relying on the DNS query's `REFUSED` reply. Primary management remained inactive while native BIND stayed active.

Both guests then rebooted. Debian boot ID changed from `f5e51c8d-e821-462a-926c-faa8a63f9fb2` to `db07b0e9-b1cb-4517-9095-e44b46f60907`; Arch changed from `84bf93bf-ab75-4a0c-82cb-4ab0e16440de` to `41f15c69-023b-4215-937e-ee179ba12987`. Both native `named.service` units were active after boot. The primary Panel and Agent remained inactive. The secondary still reported catalog serial 2 and `no matching zone` for the removed member. Direct nonrecursive UDP/TCP queries to the secondary returned `REFUSED` without authoritative data; direct UDP/TCP queries to the primary still returned authoritative (`aa`) `www.s1-kill.test A 192.0.2.11`. The native zone-state check, not `REFUSED`, establishes removal from the secondary.
