The current source-built status executable had SHA-256 `2d2c3e5931b94e85cb90f55469c706583c69a0d1cd2e63dca1a59f177a9a5943` and was `0755 root:root` in the disposable guest. This proves the read-only recorded-result path on one disposable Debian boot and the same ledger bytes produced by an earlier real rollback.
