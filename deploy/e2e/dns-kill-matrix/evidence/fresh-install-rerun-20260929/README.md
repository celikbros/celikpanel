## What this does not prove

This run exercises the fixed first-install rollback path only for a fresh standalone PowerDNS target that was masked and never started, in these two runs. It does not prove the other two states that `VerifyStoppedFreshSourceTarget` accepts (`not-found`, and `loaded`-inactive), the refused runtime-only mask, or the first-install BIND rollback. It does not prove the paired-secondary reconfiguration journals whose proof changed in the same commit. It does not cover any other matrix cell, repeat runs or flakiness. The listener proof ignores loopback and link-local sockets, and this run does not test that limit. The rolled-back verdict code is inferred, not captured. Recovery logs nothing on success, and the retry overwrites the ledger verdict. The run shows no DNS continuity, because there was nothing to continue. It does not cover reboot or power loss, owner edits, paired topology, or an Agent-independent inverse. It does not cover a signed or published release or an installed server. The standalone `peer-reachable` label is an invariance control only. Nothing here changes the 268-runnable denominator or closes P0.4. Row 4 of the acceptance register must be updated by its owner. This evidence alone is not a claim that the row passed.
